# IOS-020: 데모용 홈 탭 수동 Refresh 버튼

**Status**: Draft | **Created**: 2026-06-17 | **Author**: suyoung
**F-xxx Mapping**: Demo Mode — Manual Home Refresh | **Phase**: Demo Prep | **Priority**: High (시연 준비)

> **임시 기능(Demo-only)**: 정기 스케줄(주 2회) 기반인 IOS-008 클러스터링의 정기성이 시연 환경에서 기능 시연을 어렵게 함.
> 버튼 탭 1회로 주제 클러스터 재요청 + 섹션 순서 랜덤 셔플을 즉시 실행해 시연 중 언제든 결과를 보여줄 수 있게 한다.

---

## 1. Overview

**Problem**: 홈 탭의 주제 클러스터링(IOS-008)은 서버에서 매주 월·목 자정에 갱신되고, 섹션 순서는 `DailySeededRNG`로 하루 1회 변경된다. 시연 환경에서는 기능을 즉시 보여주기 어렵다.

**Solution**: `HomeView` 상단 헤더에 `Refresh` 버튼을 추가한다. 탭 시 `GET /api/v1/topics`와 `GET /api/v1/content`를 즉시 재호출하고, 섹션 순서를 `DailySeededRNG` 대신 완전 랜덤 시드로 셔플한다. 로딩 중에는 버튼에 `ProgressView`를 인라인으로 표시한다.

**Goals**:
- Refresh 버튼 탭 → 서버 클러스터 재요청 + 섹션 순서 즉시 재셔플
- 로딩 중 버튼 상태로 진행 중임을 시각적으로 표시
- 기존 `DailySeededRNG` 기반 자동 셔플 동작은 유지

**Non-Goals**:
- 서버에서 클러스터 재생성 강제 트리거 (기존 캐시된 클러스터 재조회만 수행)
- Pull-to-refresh 동작 변경
- 로그아웃 상태에서 클러스터 fetch (기존 동작 유지 — 로컬 섹션만 재셔플)

## 3. User Story / Behavior

**As a** Briefly 시연자,
**I want to** 홈 탭에서 Refresh 버튼을 눌러 주제 클러스터링 결과와 섹션 순서를 즉시 변경하고 싶다,
**so that** 시연 중 기능이 동작함을 청중에게 실시간으로 보여줄 수 있다.

### Key Behaviors

```
[홈 탭 헤더]
  Briefly 로고 (좌측)          [Refresh 버튼] (우측)

[Refresh 버튼 탭]
  → isRefreshing = true
  → 버튼: 텍스트 숨김 + ProgressView 표시 + disabled
  → (로그인 O) GET /api/v1/content + GET /api/v1/topics 병렬 호출
  → 응답 수신 → IOS-007 mergeServerData() 실행
  → rebuildSections(clusters:) 호출 — 이번에는 UUID 기반 완전 랜덤 시드 사용
  → isRefreshing = false
  → 버튼: 정상 상태 복원

[비로그인 상태에서 Refresh 탭]
  → 서버 fetch 없이 rebuildSections(randomSeed: true) 호출
  → 로컬 섹션 순서만 랜덤 재셔플

[로딩 중 재탭]
  → disabled 처리로 무시
```

### HomeViewModel 변경

```swift
@Published var isRefreshing = false

/// 데모용 수동 새로고침 — UUID 기반 완전 랜덤 시드로 섹션 재셔플
func demoRefresh() {
    guard !isRefreshing else { return }
    isRefreshing = true
    Task {
        defer { isRefreshing = false }
        guard let token = AuthTokenStore.shared.accessToken else {
            // 비로그인: 로컬 섹션만 랜덤 재셔플
            rebuildSections(clusters: nil, randomSeed: true)
            return
        }
        async let serverTask  = BrieflyAPI.shared.fetchServerContent(token: token)
        async let clusterTask = BrieflyAPI.shared.fetchTopicClusters(token: token)
        let serverItems = (try? await serverTask)  ?? []
        let clusters    = (try? await clusterTask) ?? []

        if !serverItems.isEmpty {
            StorageService.shared.mergeServerData(serverItems)
            localItems = StorageService.shared.loadAll().filter { $0.status != .deleted }
        }
        let localServerIds = Set(localItems.compactMap(\.serverContentId))
        let newServerItems = serverItems
            .filter { !localServerIds.contains($0.id) }
            .map { HomeItem.server($0) }
        allItems = localItems.map { .local($0) } + newServerItems
        rebuildSections(clusters: clusters.isEmpty ? nil : clusters, randomSeed: true)
    }
}
```

### rebuildSections 시그니처 변경

```swift
// randomSeed: true이면 UUID 기반 완전 랜덤 셔플, false(기본)이면 DailySeededRNG 유지
private func rebuildSections(clusters: [TopicCluster]?, randomSeed: Bool = false) {
    ...
    if randomSeed {
        utility.shuffle()   // Swift 기본 shuffle — 시스템 랜덤
    } else {
        var rng = DailySeededRNG()
        utility.shuffle(using: &rng)
    }
    sections = topicFixed + utility
}
```

## 6. Edge Cases

| Scenario | Handling |
|----------|----------|
| 로딩 중 재탭 | `disabled` + `guard !isRefreshing` 이중 방어 |
| 비로그인 상태 | 서버 fetch 없이 로컬 섹션만 랜덤 셔플 |
| 서버 fetch 실패 | 기존 로컬 데이터로 랜덤 셔플만 수행 |
| 클러스터 없음(빈 응답) | 폴백(auto_tag_category) 기반 섹션으로 랜덤 셔플 |
| Pull-to-refresh와 동시 실행 | `isLoadingServer`는 독립 — 충돌 없음 |

## 7. Testing

### 수동 검증 시나리오

1. **버튼 표시 확인**
   - 홈 탭 진입 → Briefly 로고 우측에 "Refresh" 버튼 표시 확인

2. **로딩 상태 확인**
   - Refresh 탭 → 버튼이 `ProgressView`로 전환되고 비활성화됨 확인
   - 서버 응답 후 버튼 텍스트 복원 확인

3. **섹션 순서 재셔플 확인**
   - Refresh 여러 번 탭 → 섹션(날짜별·출처별 순서)이 매번 다르게 변경 확인
   - 앱 재진입(Refresh 없이) 시에는 DailySeededRNG 기준 동일 순서 유지 확인

4. **중복 탭 방지**
   - 로딩 중 연속 탭 → 1번만 실행됨 확인

5. **비로그인 상태**
   - 로그아웃 후 Refresh 탭 → 서버 fetch 없이 섹션 순서만 변경 확인

## 8. Acceptance Criteria

- [ ] 홈 탭 헤더 로고 줄 우측에 "Refresh" 버튼이 표시된다
- [ ] Refresh 탭 시 버튼이 `ProgressView`로 전환되고 비활성화된다
- [ ] Refresh 완료 후 섹션 순서가 이전과 다르게 변경된다 (매 탭마다 랜덤)
- [ ] 앱 진입(Refresh 없이)은 기존 DailySeededRNG 순서를 유지한다
- [ ] 로딩 중 재탭을 해도 중복 실행되지 않는다
