# IOS-020: 데모용 홈 탭 수동 Refresh 버튼

**Status**: Implemented | **Created**: 2026-06-17 | **Author**: suyoung
**F-xxx Mapping**: Demo Mode — Manual Home Refresh | **Phase**: Demo Prep | **Priority**: High (시연 준비)

> **임시 기능(Demo-only)**: 정기 스케줄(주 2회) 기반인 IOS-008 클러스터링의 정기성이 시연 환경에서 기능 시연을 어렵게 함.
> 버튼 탭 1회로 주제 클러스터 재생성 + 신규 컨텐츠 반영을 즉시 실행해 시연 중 언제든 결과를 보여줄 수 있게 한다.

---

## 1. Overview

**Problem**: 홈 탭의 주제 클러스터링(IOS-008)은 서버에서 매주 월·목 자정에 갱신된다. 시연 환경에서는 새 컨텐츠를 저장하고 즉시 새 주제 클러스터를 만들어 보여주기 어렵다.

**Solution**: `HomeView` 상단 헤더에 `Refresh` 버튼을 추가한다. 탭 시 `POST /api/v1/topics/refresh`를 호출해 서버에서 클러스터링을 **동기적으로** 즉시 재실행하고, 새로 생성된 클러스터를 반환받아 홈 화면에 반영한다. 로딩 중에는 버튼에 `ProgressView`를 인라인으로 표시한다.

**Goals**:
- Refresh 버튼 탭 → 서버 즉시 재클러스터링 + 새 주제 클러스터 화면 반영
- 로딩 중 버튼 상태로 진행 중임을 시각적으로 표시
- 새로 저장한 컨텐츠가 클러스터에 포함되어 나타남

**Non-Goals**:
- 섹션 순서 랜덤 셔플 (순서 변경 없음)
- Pull-to-refresh 동작 변경
- 로그아웃 상태에서의 클러스터 fetch

## 3. User Story / Behavior

**As a** Briefly 시연자,
**I want to** 홈 탭에서 Refresh 버튼을 눌러 새로 저장한 컨텐츠가 주제별로 분류되는 것을 즉시 확인하고 싶다,
**so that** 시연 중 기능이 동작함을 청중에게 실시간으로 보여줄 수 있다.

### Key Behaviors

```
[홈 탭 헤더]
  Briefly 로고 (좌측)          [Refresh 버튼] (우측)

[Refresh 버튼 탭]
  → isRefreshing = true
  → 버튼: 텍스트 숨김 + ProgressView 표시 + disabled
  → (로그인 O) POST /api/v1/topics/refresh + GET /api/v1/content 병렬 호출
  → 서버에서 클러스터링 동기 실행 후 새 클러스터 반환
  → 응답 수신 → IOS-007 mergeServerData() 실행
  → rebuildSections(clusters: freshClusters) 호출 — 순서는 변경 없음
  → isRefreshing = false
  → 버튼: 정상 상태 복원

[비로그인 상태에서 Refresh 탭]
  → 토큰 없음 확인 후 기존 클러스터로 rebuildSections 호출 (변화 없음)

[로딩 중 재탭]
  → disabled 처리로 무시
```

### Backend: POST /api/v1/topics/refresh

백그라운드 태스크가 아닌 **동기 실행**으로 클러스터링 완료 후 새 클러스터 반환:

```python
@router.post("/refresh", response_model=TopicClustersResponse)
async def refresh_topic_clusters(user_id, db):
    await cluster_and_save_for_user(user_id)  # 동기 대기
    await db.commit()  # 트랜잭션 리셋 — 새 커밋 데이터 조회 가능
    result = await db.execute(select(UserTopicCluster).where(...))
    return TopicClustersResponse(clusters=[...])
```

### HomeViewModel: demoRefresh()

```swift
func demoRefresh() {
    guard !isRefreshing else { return }
    isRefreshing = true
    Task {
        defer { isRefreshing = false }
        guard let token = AuthTokenStore.shared.accessToken else { return }
        async let serverTask  = BrieflyAPI.shared.fetchServerContent(token: token)
        async let clusterTask = BrieflyAPI.shared.refreshTopicClusters(token: token)
        let serverItems   = (try? await serverTask)  ?? []
        let freshClusters = (try? await clusterTask) ?? []
        // 서버 데이터 병합
        if !serverItems.isEmpty {
            StorageService.shared.mergeServerData(serverItems)
            localItems = StorageService.shared.loadAll().filter { $0.status != .deleted }
        }
        allItems = localItems.map { .local($0) } + newServerItems
        withAnimation(.easeInOut(duration: 0.4)) {
            rebuildSections(clusters: freshClusters.isEmpty ? nil : freshClusters)
        }
    }
}
```

### BrieflyAPI: refreshTopicClusters()

```swift
func refreshTopicClusters(token: String) async throws -> [TopicCluster] {
    let response: TopicClustersResponse = try await post("/topics/refresh", body: [String: String](), token: token)
    return response.clusters
}
```

## 6. Edge Cases

| Scenario | Handling |
|----------|----------|
| 로딩 중 재탭 | `disabled` + `guard !isRefreshing` 이중 방어 |
| 비로그인 상태 | 토큰 없음 확인 후 조용히 종료 (기존 화면 유지) |
| 서버 클러스터링 실패 (0개 반환) | 기존 클러스터 유지 (`existingClusters` 폴백) |
| 클러스터 없음(빈 응답) | 폴백(auto_tag_category) 기반 섹션 표시 |
| Pull-to-refresh와 동시 실행 | `isLoadingServer`는 독립 — 충돌 없음 |

## 7. Testing

### 수동 검증 시나리오

1. **버튼 표시 확인**
   - 홈 탭 진입 → Briefly 로고 우측에 "Refresh" 버튼 표시 확인

2. **로딩 상태 확인**
   - Refresh 탭 → 버튼이 `ProgressView`로 전환되고 비활성화됨 확인
   - 서버 응답 후 버튼 텍스트 복원 확인

3. **새 클러스터 반영 확인**
   - 새 컨텐츠 저장 → Refresh 탭 → 새 주제 클러스터에 해당 컨텐츠 포함됨 확인
   - 클러스터 제목이 갱신됨 확인 (LLM 생성)

4. **중복 탭 방지**
   - 로딩 중 연속 탭 → 1번만 실행됨 확인

5. **섹션 순서 불변 확인**
   - Refresh 전후 섹션 순서가 유지됨 확인 (주제 섹션 상단 고정)

## 8. Acceptance Criteria

- [ ] 홈 탭 헤더 로고 줄 우측에 "Refresh" 버튼이 표시된다
- [ ] Refresh 탭 시 버튼이 `ProgressView`로 전환되고 비활성화된다
- [ ] Refresh 완료 후 새로 저장한 컨텐츠가 주제 클러스터에 반영된다
- [ ] 섹션 순서는 Refresh 전후 변경되지 않는다
- [ ] 로딩 중 재탭을 해도 중복 실행되지 않는다
